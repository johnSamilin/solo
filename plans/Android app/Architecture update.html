Updated Architecture of the Solo Mobile App for Android

Architecture Changes per Requirements

Key changes:

  1. Simplified UI: Native UI components removed; only the WebView container remains
  2. Arbitrary storage location: Support for a rootFolder anywhere in the file system
  3. No image compression: Images are saved at original quality
  4. No dark theme: Light theme only
  5. No analytics: Monitoring and analytics systems removed
  6. Multi-store: Support for publishing on Google Play and RuStore

Security Model

Path traversal protection:

fun isPathSafe(file: File): Boolean {
    val rootPath = rootFolder?.canonicalPath ?: return false
    val filePath = file.canonicalPath
    // Check that the file is inside rootFolder
    return filePath.startsWith(rootPath)
}

Permission handling:

  1. Runtime permissions: READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE
  2. Special permission: MANAGE_EXTERNAL_STORAGE (requires manual approval by the user)
  3. Storage Access Framework: For folder selection without MANAGE_EXTERNAL_STORAGE

Data isolation:

  • All file system operations are restricted to rootFolder
  • The JavaScript bridge has access only to FileSystemManager methods
  • All paths are validated for safety

Migration from electron.ts to nativeBridge.ts

Changes in the codebase:

  1. File rename: src/utils/electron.ts → src/utils/nativeBridge.ts
  2. Import updates: In all files that import electron.ts
  3. API unification: Creating a common interface for Electron and Android
  4. Platform detection: Logic for detecting the available API

New nativeBridge.ts structure:

// Common interface for all platforms
interface NativeAPI {
    readStructure(): Promise<{success: boolean, structure?: FileNode[], error?: string}>;
    openFile(path: string): Promise<{success: boolean, content?: string, error?: string}>;
    updateFile(path: string, content: string): Promise<{success: boolean, error?: string}>;
    selectFolder(): Promise<{success: boolean, path?: string, error?: string}>;
    getDataFolder(): Promise<{success: boolean, path?: string, error?: string}>;
    playTypewriterSound(): Promise<void>;
    uploadImage(base64Data: string, fileName: string): Promise<{success: boolean, url?: string, error?: string}>;
}

// Detect the available API
export function getPlatformAPI(): NativeAPI | null {
    if (window.electronAPI) {
        return window.electronAPI as NativeAPI;
    } else if (window.androidBridge) {
        return window.androidBridge as NativeAPI;
    } else {
        return null; // Web version
    }
}

This updated architecture reflects all the changes requested by the user and provides a minimalist yet functional approach to implementing the Android version of Solo.
