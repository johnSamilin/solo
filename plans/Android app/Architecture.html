App Startup Sequence

sequenceDiagram
    participant User
    participant MainActivity
    participant WebView
    participant WebViewBridge
    participant FileSystem
    participant SoloApp
    
    User->>MainActivity: Launch the app
    MainActivity->>WebView: Initialization
    MainActivity->>WebViewBridge: Create bridge
    WebView->>SoloApp: Load index.html from assets
    SoloApp->>WebViewBridge: Check bridge availability
    WebViewBridge->>FileSystem: Request file structure
    FileSystem-->>WebViewBridge: Folder structure
    WebViewBridge-->>SoloApp: Data via JavaScript
    SoloApp-->>User: Render the interface

Data Flow During Search

sequenceDiagram
    participant User
    participant SearchUI
    participant WebViewBridge
    participant SearchEngine
    participant FileSystem
    
    User->>SearchUI: Enter a search query
    SearchUI->>WebViewBridge: search(query, tags)
    WebViewBridge->>SearchEngine: Perform search
    SearchEngine->>FileSystem: Get list of HTML files
    FileSystem-->>SearchEngine: File list
    loop For each file
        SearchEngine->>FileSystem: Read contents
        FileSystem-->>SearchEngine: File text
        SearchEngine->>SearchEngine: Analyze and filter
    end
    SearchEngine-->>WebViewBridge: Search results
    WebViewBridge-->>SearchUI: Display results
    SearchUI-->>User: Show found notes

Architecture MVVM + Clean Architecture Code organization
